# FNF

A standalone site hosting Friday Night Funkin' + 430+ mods, playable in-browser.
Sister site to toby web.

## Layout

```
index.html        landing — PLAY GAME (base FNF) + BROWSE (mods)
mods.html         searchable grid of all mods
play.html?g=slug  click-to-play gate, then navigates to the game page
games/<slug>/     per-game page (index.html w/ <base href="./pkg/"> + nav overlay)
games/<slug>/pkg  junction -> real assets in X:\GN-Math-local (local dev)
data/games.json   manifest generated by tools/build.py
covers/           cover art (catalog covers or first-frame logoBumpin crops)
```

## Develop

```
python tools/build.py     # stage games (junctions — zero disk copy)
serve.bat                 # or: python serve.py 8642
# http://127.0.0.1:8642/
```

Do NOT use `python -m http.server` — its listen backlog is 5, so a game
firing 300+ asset requests gets connections dropped and the preloader
freezes on a black screen. `serve.py` uses backlog 256 + keep-alive.

## Domain-locked games — already patched

~13 Snokido builds carry an anti-leech check that hard-crashes (stack
overflow / blank nav) unless `hostname == w8.snokido.com`. The packages
are patched in place so they run on any host — no hosts file, no iframe,
no special URL. Two patch shapes, applied by `tools/patch-hostlock.py`:

- **Self-decrypting `eval("...")` wrappers** (AwiC-style): the literal is
  replaced with a plaintext copy of its decrypted payload, and the
  payload's `document.domain || document.location.hostname` feed is
  forced to the allowlisted string.
- **Inline jsjiami fingerprint checks**: the `var <flag>=!1` "allowed"
  flag that gates the `document.location = <url>` kill is flipped to `!0`.

`unlock-games.bat` now only *removes* the old hosts entry if an earlier
version ever added it. Locked slugs remain flagged `hostlock: true` in
`data/games.json` for bookkeeping.

## Deploy

```
python tools/build.py --copy   # real copies instead of junctions
```

then upload the `fnf-unblocked/` folder to the static host. ~14.5 GB of game
assets — it's heavy because FNF web builds ship all songs uncompressed.

## Notes

- 10 mods have no local assets; their pages keep the original jsDelivr
  (`cdn.jsdelivr.net/gh/bubbls/fnf-mods@main/...`) base, so they stream from
  the CDN. Mirror them later by downloading the repo paths if wanted.
- `tools/test-site.mjs` / `tools/test-games.mjs <slug>...` — playwright smoke
  tests (needs the workspace node_modules).
- Covers: catalog covers come from GN-Math's `covers/<id>.png`; other games get
  the first frame of their `logoBumpin.png` atlas (cropped via the `.xml`).
- `tools/shoot-covers.mjs` boots each non-catalog game headless and screenshots
  its title screen into `covers/raw/<slug>.png`. Re-run `python tools/build.py`
  afterward to swap those in (screenshots beat logo crops in priority). It's
  slow (~1-2 min/game, runs resumable) — safe to Ctrl+C and re-run anytime.
- `bgm.js` = site background music (starts on first click, loops, keeps its
  position across page navigations via sessionStorage).
- `nav.js` = SPA-style navigation — content swaps in place so audio never cuts.
- `tools/snokido.py` mirrors FNF builds off snokido.com (they're referer-locked,
  so each package is downloaded whole via its `manifest/default.json`). Writes
  `data/snokido-inventory.json`; re-run `python tools/build.py` to stage them
  into `games/snk-*/`. Resumable — re-run anytime to continue.
- `credits.html` lists every mod with its author (GN-Math catalog) + a link to
  its source page when known.
